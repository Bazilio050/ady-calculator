# RULES.md — Техническая спецификация и правила калькулятора ADY

## 1. Архитектурные принципы
* **NLU & Парсинг (Gemini API):** Отвечает исключительно за извлечение ключевых сущностей (raw_from, raw_to) из свободной речи пользователя. Модель НЕ выполняет тарифных расчетов и не определяет ЕСР-коды самостоятельно.
* **Детерминированный движок (Python Backend):** Выполняет 100% бизнес-логики, включая определение типов перевозки (Транзит, Импорт, Экспорт, Внутренняя), поиск расстояний и итоговое форматирование.
* **Централизация синонимов (data/stations_mapping.py):** Единственный источник правды для всех алиасов, опечаток, исторических названий, кодов ЕСР и пограничных статусов. Вся сложная логика синонимов инкапсулирована внутри справочника, модуль core/router.py очищен от условных операторов if/elif для поиска имён.

## 3. Логика типов перевозок (ShipmentType)
Определение типа перевозки происходит автоматически на основе пограничных статусов (is_border) начальной и конечной станций:

1. **Транзит (Transit):** Откуда (is_border=True) -> Куда (is_border=True)
   Пример: Ялама -> Беюк Кясик, Курык -> Беюк Кясик, Астара -> ТРК.
2. **Импорт (Import):** Откуда (is_border=True) -> Куда (is_border=False)
   Пример: Ялама -> Абшерон, ТРК -> Баладжары.
3. **Экспорт (Export):** Откуда (is_border=False) -> Куда (is_border=True)
   Пример: Абшерон -> Ялама, Гянджа -> Беюк Кясик.
4. **Внутренняя (Local/Domestic):** Откуда (is_border=False) -> Куда (is_border=False)
   Пример: Хырдалан -> Гянджа, Абшерон -> Баладжары.

## 4. Особая бизнес-логика паромных переправ и узлов (Алят)
* **Привязка к ЕСР:** Паромные и морские направления привязаны к соответствующим экспортным терминалам Алята для точного поиска расстояний в матрице:
  * Курык / Курик / Актау -> ЕСР 553002 (Ələt eksport-Kurik)
  * ТРК / Туркменбаши / Туркмен -> ЕСР 548803 (Ələt eksport-Türk.)
  * Актау -> ЕСР 549204 (Ələt eksport-Aktau)
* **Правило форматирования вывода ("Алят-эксп."):**
  Если пользователь напрямую запрашивает сокращения вроде «Алят экс/експ», система корректно определяет узел, но при форматировании вывода в интерфейсе скрывает код ЕСР, отдавая чистый интерфейсный вид: Алят-эксп. (без скобок с кодом).

## 5. Требования к коду и оформлению
* **Язык комментариев:** Все примечания и комментарии в коде оформляются СТРОГО НА РУССКОМ ЯЗЫКЕ.
* **Визуальные блоки:** Разделы файлов размечаются стандартизированными визуальными рамками вида:
  # ------------------------------------------------------------------------------
  # БЛОК X: Название блока на русском языке
  # ------------------------------------------------------------------------------
* **Многоязычность (AZ / RU / EN):** Все станции должны иметь локализованные названия для трех языков вывода с сохранением единого азербайджанского канонического ключа.

## 7. Логика расчета тарифов, Валютная система (USD / CHF) и Таблицы 3 и 4
1. **Валюта расчета:** Все итоговые тарифы провозной платы выводятся строго в **долларах США (USD)**.
2. **Валюта базовых ставок:** Все базовые таблицы (Таблица 3, Таблица 4) хранят тарифные ставки в **Швейцарских франках (CHF)** за 1 тонну.
3. **Конвертация валют:** Курс CHF -> USD подтягивается динамически из `data/currency_rates.py` по дате перевозки `shipment_date` (курс 0.79 для Q3 2026, 0.81 для Q4 2026).
   $$\text{Базовая ставка USD} = \frac{\text{Базовая ставка CHF}}{\text{Курс конвертации}}$$
4. **Выбор Базовой Таблицы:**
   * **Импорт / Экспорт:** Используют **Таблицу 3** (`data/Table_3_Tariffs.txt`, модуль `core/tables/table_3.py`).
   * **Транзит:** Использует **Таблицу 4** (`data/Table_4_Tariffs.txt`, модуль `core/tables/table_4.py`) для универсальных вагонов (крытый, полувагон, платформа).
5. **Последовательность умножения коэффициентов:**
   * **Шаг 1:** Базовая ставка в USD ($\text{CHF} / \text{Курс}$).
   * **Шаг 2:** Специфические коэффициенты по грузу/маршруту (например, 1.04 для леса и черных металлов).
   * **Шаг 3:** Коэффициент международной груженой перевозки (1.015).
   * **Шаг 4:** Коэффициент приватного вагона СПС (0.85).

7. **Транзит зерна на Туркменбаши (Ялама -> ТРК):** Авто-определение ТРК как `Ələt eksport-Türk.`, Транзит (Таблица 4), хоппер 55т, СПС.
8. **Динамический вывод:** Автоматическое определение названия базовой таблицы `(Таблица 3)` или `(Таблица 4)` в тексте вывода.
