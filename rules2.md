Контекст проекта ADY Calculator: 
Мы разрабатываем калькулятор железнодорожных тарифов ADY (Азербайджанские Железные Дороги).
Поток данных работает по цепочке: app.py -> Gemini (извлечение данных из текста в JSON) -> Pydantic-схема (core/schemas.py) -> TariffCalculator (core/calculator.py).
Архитектурный принцип добавления новых правил/коэффициентов:
Pydantic (core/schemas.py): Добавляем необходимые атрибуты/флаги (bool, float, int) в ShipmentQuery, чтобы Gemini мог извлечь их из запроса пользователя.
Калькулятор (core/calculator.py): Проверяем условия флагов из Pydantic и применимость коэффициента/правила к базовой ставке (Таблицы 3, 4, 7 и др.).
Локализация (data/translations.py): Добавляем технический код правила (rule_code) с мультиязычным описанием (RU, AZ, EN).
Формат взаимодействия:
Не придумывай ничего «от себя» и без заглушек.
При кодировании давай только точечные, минимальные блоки для вставки с корректными отступами (пробелами).
Каждый блок кода сопровождай краткой расшифровкой на человеческом языке.
