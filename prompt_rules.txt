ADY TARİF KALKULYATORU — JSON OUTPUT FORMAT INSTRUCTIONS
================================================================================

1. GENERAL FORMATTING & TOKEN SAVING RULES:
   - Return ONLY a valid JSON object.
   - Keep string values as SHORT and CONCISE as possible to minimize output tokens.
   - CARGO NAME RULE: Always include GNG code AND short text cargo name in "cargo_and_wagon" field!
     * EXAMPLE (AZ): "GNG 4704 (Kağız tullantıları), Örtülü vaqon (SPS)"
   - BASE TARIFF FORMAT RULE: Do NOT use the word "şkalası"!
     * EXAMPLE (AZ): "18.19 CHF/t (Cədvəl 3, məsafə 201-210 km, 35 t)"
   - FORMULA RULE: In "formula" field, output rate calculation divided by USD exchange rate!
     * CORRECT: "18.19 CHF/t × 0.85 × 1.015 / 0.79 = 19.86 USD/t"
     * STRICTLY FORBIDDEN: Do NOT multiply by total weight (e.g., do NOT add "× 35 t") inside formula line!
   - EXCHANGE RATE FORMAT RULE: Append exact date range from Currency_Exchange.txt!
     * EXAMPLE (AZ): "1 USD = 0.79 CHF (01.07.2026 - 30.09.2026-cı il tarixləri üzrə)"
   - PERIOD FORMAT RULE: Output full tariff policy title!
     * EXAMPLE (AZ): "ADY Tarif Siyasəti 2026-cı il"
   - FINAL RATES RULE: In "net_ady_rate" and "express_rate", output ONLY pure per-ton rate (e.g., "19.86 USD/t" or "15.69 CHF/t"). Do NOT add overall wagon total inside parentheses!
   - NOTES RULE: Keep "notes" array strictly empty `[]` to save tokens. The application script handles static notes automatically.

2. MANDATORY JSON SCHEMA STRUCTURE:
{
  "part1": {
    "route": "string",
    "shipment_type": "string",
    "distance": "string",
    "cargo_and_wagon": "string",
    "weight_info": "string",
    "period": "string"
  },
  "part2": {
    "exchange_rate": "string",
    "base_tariff": "string",
    "coefficients": [
      {
        "name": "string",
        "value": "string"
      }
    ]
  },
  "part3": {
    "formula": "string",
    "net_ady_rate": "string",
    "express_rate": "string or null",
    "notes": []
  }
}
