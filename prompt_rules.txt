ADY TARİF KALKULYATORU — JSON OUTPUT FORMAT INSTRUCTIONS
================================================================================

1. GENERAL FORMATTING & TOKEN SAVING RULES:
   - Return ONLY a valid JSON object.
   - Keep string values as SHORT and CONCISE as possible to minimize output tokens.
   - ROUTE TRANSLATION RULE:
     * AZ: "Yalama-eksp. - Böyük Kəsik-eksp."
     * RU: "Ялама-эксп. - Беюк Кесик-эксп."
     * EN: "Yalama-exp. - Boyuk Kesik-exp."
   - WAGON TYPE LANGUAGE RULE:
     * AZ: "SPS" / "MPS"
     * RU: "СПС" / "МПС"
     * EN: "SPS" / "MPS"
   - CARGO NAME RULE: Include GNG code AND short text cargo name in "cargo_and_wagon" field!
     * EXAMPLE (AZ): "GNG 72 (Qara metallar), Yarımvaqon (SPS)"
     * EXAMPLE (RU): "ГНГ 72 (Черные металлы), Полувагон (СПС)"
   - BASE TARIFF FORMAT RULE: Do NOT use the word "şkalası"! Show raw base tariff!
     * EXAMPLE (AZ): "28.53 CHF/t (Cədvəl 4, məsafə 671-680 km, 60 t)"
     * EXAMPLE (RU): "28.53 CHF/т (Таблица 4, расстояние 671-680 км, 60 т)"
   - FORMULA RULE: Include base rate, coefficients, and divide by USD exchange rate!
     * EXAMPLE: "28.53 CHF/t × 0.85 × 1.015 / 0.79 = 31.14 USD/t"
   - EXCHANGE RATE DATE FORMAT RULE (Current default = Q3 2026; If user specifies Q1 = use Q1):
     * AZ (Default Q3): "1 USD = 0.79 CHF (01.07.2026 - 30.09.2026-cı il tarixləri üzrə)"
     * AZ (If Q1 requested): "1 USD = 0.80 CHF (01.01.2026 - 31.03.2026-cı il tarixləri üzrə)"
     * RU (Default Q3): "1 USD = 0.79 CHF (на период 01.07.2026г. - 30.09.2026г.)"
     * RU (If Q1 requested): "1 USD = 0.80 CHF (на период 01.01.2026г. - 31.03.2026г.)"
   - PERIOD FORMAT RULE:
     * AZ: "ADY Tarif Siyasəti 2026-cı il"
     * RU: "Тарифная политика на 2026 фрахтовый год"
     * EN: "Tariff Policy for 2026 freight year"
   - FINAL RATES RULE: 
     * Output MANDATORY "net_ady_rate" AND "express_rate" (e.g., "31.14 USD/t" and "31.76 USD/t").
   - NOTES RULE: Keep "notes" array strictly empty `[]`.
